# Сравнение снимков

Утверждённая иерархия: `<old-version>_to_<new-version>/SUMMARY.md` и `worlds/<scenario-key>/CHANGES.md` внутри каталога сравнения.

Сравниваются структурированные данные JSON: добавление и удаление объектов, изменения параметров и итогов. В отчёте сохраняются точные версии и идентификаторы снимков, полнота и ограничения сравнения.

Этот каталог хранится в Git. Сейчас здесь только описание структуры: готовых снимков и отчётов сравнения пока нет. Каталоги сравнений создаются после получения подходящих снимков.

Правила идентификаторов, совместимости схем и повторных сравнений: [docs/DATA_LAYOUT.md](../docs/DATA_LAYOUT.md).
