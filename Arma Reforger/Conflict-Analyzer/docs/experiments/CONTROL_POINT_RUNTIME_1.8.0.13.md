# Припасы КП после инициализации HQC Everon 1.8.0.13

Измерено 07.10.2026; результаты проверены и оформлены 08.10.2026. У всех семи стартовых командных пунктов FIA собственное хранилище содержит **0 припасов при вместимости 1000**. В каждом — пять физических SUPPLIES-контейнеров по 0 / 200 и одно исключённое из суммы виртуальное представление.

[Данные измерений](CONTROL_POINT_RUNTIME_1.8.0.13.json) содержат источники, позиции, фактически созданные prefab, контейнеры, отметки времени и SHA-256 журналов. Это отдельный эксперимент над игровой сессией: опубликованные снимки конфигов r0001–r0033 сохраняются, даты их чтения не изменяются. Поле not_measured в r0033 описывает состояние проверки на момент создания той ревизии.

## Штатный сценарий — run03

Загружен `{0220741028718E7F}Missions/23_Campaign_HQC_Everon.conf`, MissionHeader присутствует. Пробник дождался IsBasesInitDone, семи инициализированных КП, созданных композиций и завершения SetInitialSupplies у всех семи. Снимок сделан через три тика секундного таймера после этого барьера. Значения общей сети прочитаны через GetSupplies / GetSuppliesMax; отдельного хранилища — из физических контейнеров потомков живой композиции GetBaseBuildingComposition.

| Контрольная точка | Хранилище КП: запас / вместимость | Запрошенный стартовый запас базы | Общая сеть: запас / вместимость |
| --- | ---: | ---: | ---: |
| Calvary Hill | 0 / 1000 | 225 | 2500 / 9800 |
| Île-aux-Saules | 0 / 1000 | 200 | 5500 / 7400 |
| Military Base Levie | 0 / 1000 | 200 | 8500 / 10800 |
| Montignac | 0 / 1000 | 250 | 4000 / 8300 |
| Power Plant | 0 / 1000 | 250 | 5100 / 7000 |
| Régina | 0 / 1000 | 225 | 400 / 5300 |
| Transformer Station | 0 / 1000 | 100 | 4000 / 7300 |

Во всех семи вызовах SetInitialSupplies запас общей сети до и после совпал. Он уже превышал запрошенную стартовую величину, поэтому штатный код не добавил припасы. Эта величина задаётся случайно; числа в таблице относятся к данному запуску и не являются постоянными настройками мира. Вместимость общей сети не следует подменять суммой объектов, сгруппированных по близости на карте.

Run03 завершился после первого полного снимка всех семи КП, до повторных проб и отметки COMPLETE. Поэтому стабильность во времени для штатного MissionHeader этим запуском не подтверждена. Причина завершения не установлена; журнал содержит начало shutdown. В JSON measurementComplete=false, stableAcrossSamples=null.

## Дополнительный запуск мира — run01

Прямой запуск CTI_Campaign_HQC_Eden.ent с ConflictSystems.conf без MissionHeader завершил все три измерения: через 3, 8 и 15 тиков после того же барьера. У всех семи КП физический запас 0 / 1000 и агрегаты сети оставались одинаковыми. Стартовые случайные задания отличались от run03 и также не вызывали пополнения. Этот запуск подтверждает повторяемость наблюдения, но отдельно обозначен как direct world, а не запуск штатного MissionHeader.

## Метод и ограничения

Использован ArmaReforgerSteamDiag 1.8.0.13, отдельный диагностический addon и отдельный профиль для каждого запуска. Пробник оборачивает SetInitialSupplies с обязательным вызовом штатного super, читает состояние и не задаёт собственные значения ресурсов. Геттеры общей сети штатно обновляют её агрегаты. Исходные ресурсы мира не сохранялись; игровые профили и возможные сохранения находятся вне репозитория.

Проверены точное имя source и позиция КП с допуском 0.025 м для округлённой строки игрового журнала, уникальность runtime entity ID + container index в каждом хранилище, суммы физических слотов и исключение виртуальных. Между сессиями runtime ID не являются постоянными идентификаторами. Всего проверено 28 снимков хранилищ (21 + 7), каждый по пять физических слотов.

SHA-256 исходника пробника в JSON относится только к run03: между запусками добавлен переход к MissionHeader. SHA-256 каждого журнала относится к своему запуску. Сырые журналы, профили, сохранения и код базовой игры не публикуются. Неудачный промежуточный run02 не включён: при переходе сценария он потерял диагностический addon.

Измерены только стартовые композиции FIA. US / USSR, захват КП, дальнейшее снабжение и распределение ресурсов по всем соседним хранилищам требуют отдельных опытов. Автоматическая runtime-команда обычного Workbench-помощника пока не реализована.
