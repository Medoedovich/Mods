# Диагностика editor source

Первый прототип читает открытый мир в World Editor и сериализует выбранные источники в JSON. Это исследовательский отчёт со статусом `partial`, не итоговый `data.json` архива и не подсчёт фактически появившихся объектов.

## Команда

В World Editor: `Plugins → [ME] Conflict Analyzer → Diagnostics → Export world source diagnostics`.

Плагин читает текущее состояние открытой сцены, включая несохранённые изменения пользователя. Для воспроизводимого анализа запускайте отдельный Workbench на сохранённом ресурсе мира. Плагин не сохраняет сцену, не создаёт объекты и не переключает режим игры. CLI открывает запрошенный ресурс и проверяет, что загружен именно он.

Прямая файловая выгрузка предназначена для `exports/` рядом с addon. Существующий файл не перезаписывается; без параметра имени выбирается свободный `ME_CA_WorldDiagnostics_N.json`. Workbench может запросить у пользователя разрешение на FileIO. Этот путь требует отдельной интерактивной проверки; автоматический эксперимент выполнен через журнал.

## Проверяемый режим CLI

Пути ниже соответствуют одной локальной установке; укажите свои пути к программе, addon и базовой игре.

```powershell
$exe = 'D:\SteamLibrary\steamapps\common\Arma Reforger Tools\Workbench\ArmaReforgerWorkbenchSteamDiag.exe'
$project = 'C:\Users\Phil\Documents\GitHub\Arma Reforger\Mods\Conflict Analyzer\ME_Conflict_Analyzer\addon.gproj'
$baseAddons = 'D:\SteamLibrary\steamapps\common\Arma Reforger\addons'
$arguments = '-gproj "' + $project + '" -addonsDir "' + $baseAddons + '" -wbModule=WorldEditor -run -exitAfterInit -plugin=ME_CA_WorldDiagnosticsPlugin -ME_CA_World=worlds/MP/CTI_Campaign_HQC_Eden.ent -ME_CA_LogJson=1'
$process = Start-Process -FilePath $exe -ArgumentList $arguments -WorkingDirectory (Split-Path $exe -Parent) -WindowStyle Hidden -PassThru
```

После завершения именно этого процесса выберите его `console.log` в `Documents/My Games/ArmaReforgerWorkbench/logs/`. Не берите молча журнал последнего запуска: одновременно могут работать другие экземпляры.

```powershell
& './tools/Convert-DiagnosticsLog.ps1' -LogPath '<путь к console.log этого запуска>' -OutputPath './exports/HQC_Eden_Diagnostics.json'
```

Создайте каталог `exports/` перед сборкой файла. Конвертер требует один завершённый успешный отчёт, проверяет длину JSON, его синтаксис и счётчики и отказывается перезаписывать существующий файл. Режим `-ME_CA_LogJson=1` использует сериализацию и журнал, не вызывает FileIO из игрового скрипта.

Для прямого экспорта доступен `-ME_CA_OutputFile=HQC_Eden_Diagnostics.json`: это имя файла внутри `exports/`, без каталогов. Параметры плагина идут после `-plugin`; `GetCmdLine` читает их с начальным дефисом.

## Что входит в JSON

- Путь открытого мира, версия игры, время UTC, версии схемы и диагностического прототипа.
- Число editor source до и после чтения, число уникальных посещённых источников и выбранных записей.
- Имя, класс, editor source ID, родительские ID, subscene, слой и ближайший ресурс prefab.
- Локальная позиция, позиция из `IEntity.GetOrigin()`, независимый расчёт через матрицы родителей и расхождение между ними. Исходные `angles` имеют порядок pitch/yaw/roll; `Math3D.AnglesToMatrix` принимает yaw/pitch/roll. В расчёт входят масштабы родителей и `RELATIVE_Y` корня с высотой поверхности; отдельная проверка масштаба, отличного от единицы, ещё нужна.
- Поля выбранных компонентов: имя, тип, доступное значение, enum-метка и признак прямого переопределения. `BaseContainer.Get` читает также доступные унаследованные значения и значения по умолчанию; отсутствие прямого override само по себе не доказывает конкретный источник наследования.

Отбираются классы с префиксами `SCR_Campaign`, `SCR_Ambient`, `SCR_Resource`, а также `SCR_FactionAffiliationComponent`, `SCR_GameModeCampaign`, `SCR_AIGroup`, `SCR_CacheManagerComponent`. Это широкий фильтр для исследования; он включает и служебные компоненты, которые не должны попасть в игровые итоги. Обход учитывает дочерние source и предотвращает повторное посещение одного source.

Обход не ограничен слоем выбранного сценария: он читает загруженную сцену вместе с родительским миром, для HQC Everon — Eden. Сохраняемый объём уже меньше полного мира, но фильтр и перечень полей шире нужного игрового отчёта. Согласно [алгоритму экспорта](EXPORT_ALGORITHM.md), этот режим остаётся диагностикой. Отдельный [целевой экспорт баз-источников](SUPPLY_SOURCES.md) уже использует точный класс, четыре поля и JSON своего отчёта. Родительский мир читается для нужных данных и не исключается целиком.

Порог расхождения координат — 0,02 м. Неизвестная позиция остаётся `unknown`; несовпадение обозначается `mismatch`. Editor ID пока нельзя считать гарантированным ключом между версиями игры.

## Ограничения

Объектные поля и массивы объектов перечисляются как `not_exported`; каталоги фракций и вложенные конфиги ещё не разрешаются. Прототип не переводит поля в игровые единицы, не суммирует склады, не выбирает HQ, не вычисляет состав случайных групп и не строит четыре финальные таблицы. Количество найденных компонентов нельзя выдавать за количество бойцов, выбранных баз или созданных машин.

Полный состав addon, GUID сценария, устойчивые ключи для сравнения версий и цепочки происхождения каждого значения остаются в TODO. Сравнение количества source до и после — ограниченная проверка; само по себе оно не доказывает неизменность всех свойств сцены. В коде анализа используются чтение, сериализация и вывод, без операций создания/изменения/сохранения мира.
