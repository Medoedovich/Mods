[h1]Test Range[/h1]
A minimal terrain for testing mods and gameplay mechanics.

[list]
[*]1024 × 1024 metre world.
[*]Flat concrete interior at absolute elevation +1 m, X/Z=4…1016 (1012 × 1012 m between flat height samples), with a narrow coastal edge and surrounding ocean.
[*]No buildings, roads, vegetation or placed objects.
[*]New player spawn at X=512, Z=512 with the included mission.
[*]No automatic infected, animals, vehicles or loot with the included mission.
[*]Vanilla game resources only; no third-party mod dependencies.
[/list]

The central 250 × 250 metre test area is X/Z=387…637. It is a logical area on the same uniform surface, without markings or barriers.

[h2]Offline use[/h2]
Start Steam, open this mod's folder and double-click Start-Offline.cmd. The diagnostic client is selected by default; -Retail selects the regular client. No separate server or Community Offline Mode is needed. See README-SETUP.md for game path overrides and additional mods.

The included mission does not initialize the automatic economy. Other missions or mods can change spawning behavior. Normal survival mechanics remain enabled. The PBOs are intentionally unsigned for offline use.

[h2]Scope[/h2]
Tested on Windows with game version 1.30.164200.56. Intended for local offline mod development. Some mods need a server context. AI navmesh, admin tools, item spawners and a free camera are not included. Ordinary dedicated server compatibility is not claimed as tested.

The cover is generated promotional artwork. The four gallery images are actual in-game screenshots.

Based on the official Bohemia Interactive Terrain Sample. Sample-derived material is distributed under ADPL-SA; see LICENSE.md. This is a community mod.

[h2]Русский[/h2]
[h1]Test Range[/h1]
Минималистичная карта для проверки модов и игровых механик.

[list]
[*]Мир размером 1024×1024 метра.
[*]Ровный бетон на абсолютной высоте +1 м в X/Z=4…1016 (1012×1012 м между крайними ровными узлами), узкая береговая кромка и океан вокруг.
[*]Без зданий, дорог, растительности и размещённых объектов.
[*]Новый игрок появляется в центре: X=512, Z=512.
[*]С комплектной миссией нет автоматического появления заражённых, животных, транспорта и лута.
[*]Только стандартные ресурсы игры, без сторонних зависимостей.
[/list]

Центральная тестовая зона 250×250 м — диапазон X/Z=387…637. Она задана координатами и использует ту же поверхность, без разметки и ограждений.

[h2]Offline-запуск[/h2]
Запусти Steam, открой папку мода и дважды щёлкни Start-Offline.cmd. По умолчанию используется диагностический клиент; ключ -Retail выбирает обычный клиент. Отдельный сервер и Community Offline Mode не нужны. Ручной путь к игре и дополнительные моды описаны в README-SETUP.md.

Комплектная миссия не инициализирует автоматическую экономику. Другая миссия или дополнительные моды могут изменить спавн. Обычные механики выживания сохранены. PBO поставляются без подписи: для offline она не требуется.

[h2]Область применения[/h2]
Проверено под Windows на версии игры 1.30.164200.56. Назначение — локальная разработка модов в offline. Некоторым модам необходим серверный контекст. Navmesh, инструменты администратора, спавнер предметов и свободная камера не включены. Совместимость с обычным выделенным сервером не заявляется как проверенная.

Обложка — сгенерированная иллюстрация. Четыре изображения галереи — реальные кадры из игры.

Проект основан на официальном Terrain Sample Bohemia Interactive. Материалы на основе примера распространяются по ADPL-SA; подробности в LICENSE.md. Пользовательский мод сообщества.
