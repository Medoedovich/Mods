# Workshop media

Public item: [Test Range](https://steamcommunity.com/sharedfiles/filedetails/?id=3826868718), item ID `3826868718`.

`preview.jpg` is the current 1254 × 1254 cover with the title TEST RANGE. It was edited with the built-in image_gen tool; the final PNG is `cover-generated-v2.png` and the prompt is in `image-prompt.txt`. The cover is promotional artwork.

The four JPGs in `gallery/` are unaltered 1920 × 1080 Steam screenshots of the final build: overview, top-down, shore and ground level. They contain no HUD or performance overlay. Their terrain matches the PBO hashes in `../docs/artifacts.json`.

The descriptions are stored in English, Russian and combined BBCode form. They include the public Discord contact supplied by the author. For future Publisher updates, use the existing Workshop item and `dist/@DayZTestRange` as content. This folder is media/source material and is not itself the playable mod folder.
