# Перемещения

Приоритет направления: **P0**. Статус: **Запланировано**. Категория: `movement`.

[Все направления](README.md) · [Общий формат и правила](../LOGGING_SPEC.md)

Цель — получать приблизительные маршруты и географический контекст действий без записи позиции каждый кадр.

## События и приоритет реализации

| Событие | Приоритет | Статус | Когда записываем |
|---|---|---|---|
| `movement.position_sampled` | P0 | Запланировано | При периодической проверке и выполнении условий записи |
| `movement.teleported` | P2 | Запланировано | При подтверждённой телепортации из известной интеграции |

## Данные событий

| Контекст | Данные сверх общего конверта |
|---|---|
| Замер | Причина замера, известный способ движения; позиция в общем конверте |
| Транспорт | Известные тип/ID транспорта и место игрока, если доступны |
| Телепортация | Начальная и конечная позиции, причина и подтверждённый инициатор |

## Работы по этапам

| Работа | Приоритет | Критерий готовности |
|---|---|---|
| Проверка позиции каждые 60 секунд | P0 | Сохраняется смещение от последнего записанного замера от 25 м |
| Контроль стоящего игрока | P0 | Есть замер не реже одного раза в 5 минут |
| Географические представления | P1 | Карта показывает время точек и разрывы, а не непрерывный достоверный трек |
| Интеграция подтверждённых телепортаций | P2 | Есть источник факта; большой скачок позиции сам по себе не считается телепортацией |

## Правила и проверки

- Вход, выход и смерть уже содержат свою позицию; отдельная копия замера для того же факта не нужна.
- Последняя позиция с прошлого момента всегда сопровождается временем её получения.
- Между замерами игрок может уйти и вернуться незамеченным. По двум точкам нельзя обещать точный пройденный путь.
- Проверить движение пешком, в транспорте, стояние, возвращение к исходной точке, выход и рестарт. Разрывы сессий/неизвестные интервалы отображать явно.

Зависимости: [сессии](sessions.md), [персонаж](character.md); транспорт — [отдельное направление](vehicles.md). Для баланса используем агрегированные показатели перемещения и обобщённые области карты. Индивидуальные маршруты и точные точки допускаются только для ограниченной технической диагностики по [принципам проекта](../GOALS.md); оперативное отслеживание ради игрового преимущества запрещено.
