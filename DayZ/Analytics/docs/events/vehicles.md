# Транспорт

Приоритет направления: **P1**. Статус: **Запланировано**. Категория: `vehicle`.

[Все направления](README.md) · [Общий формат и правила](../LOGGING_SPEC.md)

Цель — связывать игроков с использованием транспорта и фиксировать изменение состояния машины.

## События и приоритет реализации

| Событие | Приоритет | Статус | Когда записываем |
|---|---|---|---|
| `vehicle.entered` | P1 | Запланировано | После фактической посадки игрока на место |
| `vehicle.exited` | P1 | Запланировано | После фактического выхода игрока из транспорта |
| `vehicle.engine_changed` | P1 | Запланировано | При подтверждённом изменении состояния двигателя |
| `vehicle.destroyed` | P1 | Запланировано | При подтверждённом разрушении транспорта |

## Данные событий

| Контекст | Данные сверх общего конверта |
|---|---|
| Транспорт | Classname, ID сущности с областью действия, позиция |
| Место | Индекс/роль места, известные водитель/пассажиры в момент события |
| Двигатель | Предыдущее/новое состояние, подтверждённый инициатор и причина, если известны |
| Разрушение | Наблюдаемый источник, доступное состояние транспорта, время контекста |

В посадке/выходе игрок находится в `actor`, транспорт — в `target`. Для изменения двигателя/разрушения инициатор может быть неизвестен. Водителя нельзя автоматически считать виновником разрушения.

## Работы по этапам

| Работа | Приоритет | Критерий готовности |
|---|---|---|
| Посадка, выход и смена места | P1 | Переход между местами не создаёт ложный выход из машины |
| Двигатель | P1 | Фиксируется реальное состояние, не только нажатие команды запуска |
| Разрушение | P1 | Одно событие на факт; обычное удаление/очистка отличается от разрушения |
| Дополнительный контекст топлива, скорости и состояния | P2 | Есть единицы и время замера, объём записи ограничен |
| Транспорт сторонних модов | P2 | Поддержка типов и событий подтверждена для каждой интеграции |

## Правила и проверки

- Неудачная попытка запуска не является сменой состояния двигателя.
- Маршрут игрока в транспорте остаётся в [перемещениях](movement.md); вторую постоянную запись координат не добавлять без отдельной задачи.
- Проверить водителя/пассажира, смену места, выход/отключение в машине, запуск/остановку/заглохший двигатель и разрушение без известного источника.

Зависимости: [сессии](sessions.md), [перемещения](movement.md). Представления — использование машин, поездки и история транспортной сущности.
