# Бой

Приоритет направления: **P0**. Статус: **Запланировано**. Категория: `combat`.

[Все направления](README.md) · [Общий формат и правила](../LOGGING_SPEC.md)

Цель — восстанавливать урон и применение оружия с известным источником и целью.

## События и приоритет реализации

| Событие | Приоритет | Статус | Когда записываем |
|---|---|---|---|
| `combat.hit` | P0 | Запланировано | При подтверждённом уроне игроку от игрока, сущности или среды |
| `combat.shots_summary` | P0 | Запланировано | Итог окна выстрелов длительностью до 5 секунд |
| `combat.shot_fired` | P2 | Запланировано | Каждый выстрел в отдельно включённом подробном режиме |

## Данные событий

| Контекст | Данные сверх общего конверта |
|---|---|
| Попадание | Источник и цель, их позиции, тип урона, оружие, боеприпас, зона попадания, дистанция |
| Изменение здоровья | `reported_damage`, доступные Health до/после и `health_delta` с явными единицами |
| Сводка выстрелов | Оружие, боеприпас при доступности, количество, время начала/конца окна |
| Одиночный выстрел | Оружие, боеприпас, позиция; дополнительные сведения только при проверенной доступности |

В `combat.hit` позиция конверта — позиция цели; игрок-инициатор попадает в `actor` только при подтверждённой связи с источником. Иначе `actor: null`, сущность/среда описываются в `data`.

## Работы по этапам

| Работа | Приоритет | Критерий готовности |
|---|---|---|
| Урон и известный источник | P0 | Не склеиваются разные источники/цели; неизвестный источник отмечен явно |
| Окна выстрелов и сброс остатка | P0 | Смена оружия, выход и штатная остановка не теряют незакрытое окно |
| Расширенный контекст для карточки боя | P1 | Связь с другими наблюдениями не создаёт повторного факта смерти |
| Подробный режим выстрелов | P2 | Включается отдельно; инструменты не суммируют его повторно со сводками |

## Правила и проверки

- Урон из callback и фактическое уменьшение Health — разные показатели; не подменять их друг другом.
- В сводках разделять игроков, оружие и разные известные типы боеприпасов. Хранить реальные границы окна.
- При подробном режиме явно различать одиночные записи и сводки; число выстрелов считать по выбранному источнику.
- Проверить огнестрел, ближний бой, заражённого, животное, падение, взрыв, транспорт, смену оружия и выход посреди окна.
- Смерть хранится в [персонаже](character.md); факт убийства не дублируется отдельным выдуманным событием.

Зависимости: [сессии](sessions.md), [персонаж](character.md), позиции. Представления — бой, оружие, урон и контекст смерти.
