# Питание и питьё

Приоритет направления: **P0**. Статус: **Запланировано**. Техническая категория: `survival`.

[Все направления](README.md) · [Общий формат и правила](../LOGGING_SPEC.md) · [Лечение](medical.md)

Цель — понимать, чем и в каком количестве игрок питался и откуда получал воду. Питание имеет отдельный файл; код существующего события сохраняется.

## События и приоритет реализации

| Событие | Приоритет | Статус | Когда записываем |
|---|---|---|---|
| `survival.item_consumed` | P0 | Запланировано | По итогу действия с фактическим употреблением еды/жидкости, включая частичное выполнение |

## Данные события

| Контекст | Данные сверх общего конверта |
|---|---|
| Вид | `consumption_kind`: еда или питьё |
| Источник | Classname предмета либо тип природного/мирового источника, его известная позиция |
| Количество | Фактически израсходованное количество и проверенная единица; недоступное значение — `null` |
| Действие | Время начала/конца или длительность; `outcome: success` / `partial` |

Сам употребляющий игрок находится в `actor`; предмет/источник при доступности — в `target`. Вода из источника не требует вымышленного ID предмета.

## Работы по этапам

| Работа | Приоритет | Критерий готовности |
|---|---|---|
| Употребление еды и питьё из предмета | P0 | Записывается фактический расход за действие, без записи каждого внутреннего тика |
| Питьё из мирового источника | P0 | Источник обозначен явно; неизвестный объём не заменяется нулём |
| Частично выполненное действие | P0 | При отмене после расхода сохраняется одна итоговая запись с `partial` |
| Контекст голода/жажды до и после | P1 | Известны единицы и время замеров; показатели не принимаются за усвоенное количество |

## Правила и проверки

- Отмена без фактического расхода не создаёт событие P0. Запись о начале действия не доказывает употребление.
- Расход предмета и изменение энергии/гидратации — разные наблюдения; они могут происходить в разное время.
- Не переводить внутренние игровые единицы в граммы/миллилитры без проверки.
- Проверить еду, жидкость из ёмкости, мировой источник, частичное употребление, отмену без эффекта, опустошение/удаление предмета и повторные callback.

Зависимости: [сессии](sessions.md), контекст [инвентаря](inventory.md). Общие замеры организма описаны в [лечении](medical.md). Представления — история питания, расход продуктов/воды и сравнение источников.
