# Proxy Placement Tool — Alpha

Автор: **Medoedovich**. Версия: **0.1.0-alpha**.

Офлайн-редактор для подбора позиции и углов предметов относительно зданий и остовов с экспортом в CE `dispatch`. Запуск — **только через DayZDiag**. Проверенная сборка: DayZDiag **1.30.164289.70**.

**Это alpha. Сохранения и открытия проектов пока нет. Перед выходом экспортируй нужные XML: после перезапуска сцена начинается заново. Экспортированные файлы сохраняются.**

## Установка и запуск

1. Установи DayZ и DayZ Tools, подготовь `DayZDiag_x64.exe` соответствующей версии в папке установленной игры. Steam должен быть запущен.
2. Подпишись на этот инструмент и на [Test Range](https://steamcommunity.com/sharedfiles/filedetails/?id=3826868718). Дождись загрузки обоих модов.
3. Открой папку установленного инструмента (`steamapps\workshop\content\221100\<ID этого инструмента>`) и запусти `Start-Editor.cmd`.
4. Закрой уже запущенный клиент DayZ перед запуском редактора. Слева появится создание объектов, справа — точная настройка, снизу — созданные предметы.

Скрипт находит Steam-библиотеки, DayZDiag и Test Range автоматически. Можно явно передать пути:

```bat
Start-Editor.cmd -Game "X:\SteamLibrary\steamapps\common\DayZ" -TestRange "X:\SteamLibrary\steamapps\workshop\content\221100\3826868718"
```

Дополнительные моды с предметами/зданиями:

```bat
Start-Editor.cmd -ExtraMods "X:\Mods\@One;X:\Mods\@Two"
```

Проверка путей без запуска игры и без записи файлов: `Start-Editor.cmd -CheckOnly`. Обычный клиент, сервер и мультиплеер этой alpha не поддерживаются. Подключение мода в обычном DayZ Launcher само по себе редактор не открывает: используй указанный offline-запуск.

## Основной сценарий

1. Слева выбери «Здания / остовы», введи часть classname, выбери результат и нажми создание. Объект станет опорой, камера покажет его целиком.
2. Во вкладке «Предметы» найди нужный classname и создай предмет рядом с опорой.
3. Щёлкни по предмету в мире или по его карточке снизу. **F7** — стрелки перемещения, **F8** — кольца вращения. Точные координаты и углы вводятся справа.
4. Щелчок по пустому месту снимает выбор. **F9** возвращает выбранный предмет в положение на момент его выбора.
5. **F4** — проверка персонажем: можно подойти к предмету, проверить действие «Взять» и `Tab → Поблизости`. Закрой инвентарь и нажми F4 для возврата в редактор.
6. Создавай следующие опоры без перезапуска. Выбирай их справа; нижняя панель содержит созданные предметы всех опор. ‹/› перелистывают список, номер различает одинаковые вещи.
7. Слева нажми **«XML всей опоры»**, чтобы сохранить все связанные предметы. **F10** сохраняет выбранный предмет и одновременно XML всей опоры.

Камера: **F1** переключает курсор и полёт; WASD, Q/Z и мышь управляют полётом. Колёсико задаёт множитель 0.1–16, подпись появляется под центральным прицелом. Shift/Ctrl временно ускоряют полёт, Alt замедляет. **F11** показывает диагностические мировые координаты.

Интерфейс выбирает русский или английский по языку клиента DayZDiag. Для остальных языков используется английский. Поиск показывает первые 100 совпадений; уточняй запрос. В нижнее поле Classname можно ввести полное имя. Каталог берётся из загруженных конфигов; работоспособность всех сторонних классов не гарантируется.

## Где лежит результат

По умолчанию:

```text
%LOCALAPPDATA%\ProxyPlacementTool\profiles\ProxyPlacement\<classname опоры>\<сеанс UTC>_scene_<номер>.xml
```

Повторный экспорт той же опоры в текущем сеансе обновляет её файл. Новые сеансы и другие опоры получают отдельные файлы. Предметы в руках/инвентаре не включаются в экспорт, пока не окажутся на земле. `selection.xml` и `<classname>.proxy.xml` — дополнительные файлы последнего выбранного предмета.

Папка `profiles` содержит журналы игры. Папка `sessions` хранит служебные копии стартовой миссии, **а не сохранённые проекты**; они не восстанавливают размещение. Workshop-папка при запуске не изменяется. Другой каталог данных можно указать параметром `-RuntimeRoot`.

## Применение к экономике лута

Экспорт содержит фрагмент для `mapgroupproto.xml`, например:

```xml
<group name="Land_Garage_Row_Small">
  <dispatch>
    <proxy type="CanisterGasoline" pos="0 0.2 0" rpy="20 0 0" />
  </dispatch>
</group>
```

Значения здесь иллюстративные; используй координаты своего экспорта. Добавь `dispatch` в соответствующий прототип, сохрани нужные обычные контейнеры и остальные настройки здания. Для итогового появления предмета также нужны экземпляр здания, зарегистрированная группа и подходящие настройки экономики, включая `types.xml`.

Редактор не устанавливает экспорт автоматически на сервер. Предпросмотр создаётся скриптом; в целевой миссии предметы должна создавать CE. Сравни результат после нового запуска тестовой экономики. Экспортированные файлы разделены по экземплярам для удобства работы, но CE-прототип с одним classname обычно применяется ко всем его экземплярам: не добавляй несколько одноимённых групп вслепую.

## Ограничения alpha

- Сохранение/загрузка проекта, удаление через меню и undo/redo будут рассматриваться в следующих версиях.
- Опора имеет ориентацию 0 и масштаб 1. Поворот самой опоры не поддерживается; преобразование проверено для CE-группы `rpy="0 0 0" a="90"`.
- Готовые XML требуют настройки целевой миссии; обычный лут автоматически не перестраивается.
- Проверки в обычном клиенте и мультиплеере не заявлены. Эта версия предназначена для авторов конфигурации на offline-площадке Test Range.

При сообщении об ошибке приложи версию DayZDiag, classnames опоры/предмета, шаги воспроизведения и соответствующие строки RPT/script log. XML помогает проверить ошибки позиции и углов.
