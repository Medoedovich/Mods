# Proxy Placement Tool

Автор **Medoedovich**, версия **1.0.0**.

Офлайн-редактор для подбора позиции и углов предметов относительно зданий и остовов с экспортом в CE `dispatch`. Запуск — **только через DayZDiag**. Проверенная сборка: DayZDiag **1.30.164289.70**.

Используй **«Сохранить проект»**, чтобы сохранить редактируемую сцену, и **«Открыть проект»**, чтобы продолжить после перезапуска. XML для целевой миссии выгружается отдельно.

## Установка и запуск

1. Установи DayZ и DayZ Tools, подготовь `DayZDiag_x64.exe` соответствующей версии в папке установленной игры. Steam должен быть запущен.
2. Подпишись на этот инструмент и на [Test Range](https://steamcommunity.com/sharedfiles/filedetails/?id=3826868718). Дождись загрузки обоих модов.
3. Открой папку установленного инструмента (`steamapps\workshop\content\221100\<ID этого инструмента>`) и запусти `Start-Editor.cmd`.
4. Закрой уже запущенный клиент DayZ перед запуском редактора. Каталог и список «Объекты на сцене» находятся слева, свойства выбранного объекта — справа.

Скрипт находит Steam-библиотеки, DayZDiag и Test Range автоматически. Можно явно передать пути:

```bat
Start-Editor.cmd -Game "X:\SteamLibrary\steamapps\common\DayZ" -TestRange "X:\SteamLibrary\steamapps\workshop\content\221100\3826868718"
```

Дополнительные моды с предметами/зданиями:

```bat
Start-Editor.cmd -ExtraMods "X:\Mods\@One;X:\Mods\@Two"
```

Проверка путей без запуска игры и без записи файлов: `Start-Editor.cmd -CheckOnly`. Обычный клиент, сервер и мультиплеер этим редактором не поддерживаются. Подключение мода в обычном DayZ Launcher само по себе редактор не открывает: используй указанный offline-запуск.

## Рабочий процесс

1. **Добавь опору.** Выбери карту и здание/остов во вкладке «Объекты» и перетащи его в сцену.
2. **Покажи штатные точки лута.** Включи иконку цилиндра в разделе «Просмотр». Учитывай показанные объёмы при выборе места для новых Proxy. Это справочный слой; реальные предметы на штатных точках он не создаёт.
3. **Размести предметы и проверь доступность.** Перетащи вещи из каталога, настрой позиции и углы. Через **F4 / «Персонаж»** проверь размещение по критериям ниже, затем вернись в редактор.
4. **Сохрани проект и экспортируй XML.** Проект позволяет продолжить редактирование. **«XML всей опоры»** выгружает размещённые предметы для подключения к CE; сохранение проекта и экспорт XML — отдельные действия.
5. **Подключи экспорт к целевой миссии.** Объедини `dispatch` с нужной группой в `mapgroupproto.xml`, сохранив штатные контейнеры и остальные нужные настройки. Проверь настройки экономики, включая `types.xml`. Подробности — в разделах [«Где лежит результат»](#где-лежит-результат) и [«Применение к экономике лута»](#применение-к-экономике-лута).
6. **Проверь фактический спавн.** Запусти миссию с CE и сравни позиции, углы и доступность появившихся вещей с редактором. Для контрольной проверки подходит отдельная офлайн-миссия DayZDiag с нужными XML. Проверяемый лут должна создавать сама экономика: **F4 в редакторе проверяет скриптовый предпросмотр и не подтверждает спавн через CE**.

Первый контрольный запуск подтверждает работу экспорта с выбранной конфигурацией миссии. Повторная проверка особенно полезна для нового classname предмета, сильного наклона, тесной полки или размещения внутри остова.

### Критерии проверки точки

- **Позиция и углы:** после создания через CE предмет находится в задуманном месте и сохраняет выбранный наклон.
- **Пересечения:** нет нежелательного проникновения в стены, пол, мебель или другие предметы. Учитываются объёмы штатных точек лута и возможное соседство с обычным лутом.
- **Действие «Взять»:** при подходе появляется доступное действие, и предмет действительно можно взять обычным для него способом.
- **«Поблизости»:** предмет отображается в соответствующем разделе открытого инвентаря, когда персонаж находится рядом.

В редакторе оцениваются геометрия и доступность предпросмотра. После подключения XML те же критерии применяются к предметам, созданным CE в целевой миссии.

## Работа

- В разделе **«Объекты»** раскрой карту и категорию или найди classname. Перетащи строку здания/остова на поверхность внутри рамки мира. Камера покажет созданную опору целиком. Обычный щелчок только выбирает строку каталога.
- В сцене **одна опора**. Перенос другой открывает **«Заменить / Отмена»**; Escape отменяет замену. Подтверждение удаляет старую опору и размещённые предметы после проверки нового объекта. Персонаж, инвентарь и выгруженные XML сохраняются. При несохранённых изменениях доступны «Сохранить / Не сохранять / Отмена». Раскладку можно сохранить в проект или выгрузить в XML.
- **«Показывать StaticObj»** по умолчанию выключен. Каталоги сохраняют раскрытые ветки; жилые здания и остовы имеют дополнительные подкатегории.
- Во вкладке **«Предметы»** найди вещь по локализованному названию или classname и перетащи на поверхность внутри рамки. Наведение показывает 3D-превью и полный classname. Повторный перенос создаёт отдельный экземпляр, количество не ограничено. Отпускание за рамкой или над небом отменяет создание.
- Выбирай вещь по модели или строке **«Объекты на сцене»** под каталогом. Щелчок по пустому месту снимает выбор. **F7 / «Движение»** включает стрелки, **F8 / «Поворот»** — кольца вращения. Перенос останавливается при выходе за рамку; продолжение требует нового нажатия.
- **«Свойства объекта»** показывают позицию в режиме движения и Roll/Pitch/Yaw в режиме поворота. Корректные числа применяются сразу. Иконка сброса возвращает один компонент к значению на момент выделения; **F9** сбрасывает положение целиком. **«Тонкая настройка»** открывает шаговые кнопки.
- Персонажа и опору также можно выбрать в списке и перемещать штатным Gizmo или числовыми полями. Перемещение опоры оставляет предметы на прежних местах. Координаты вещей — относительно опоры; позиция персонажа и опоры — мировая. Вращение доступно только предметам.
- Удерживай **ПКМ** над сценой для полёта. Отпусти, чтобы вернуть курсор. WASD — движение, Q — подъём, Z — спуск. Колёсико меняет множитель от 0,1× до 16×, который ненадолго появляется под прицелом. Иконка камеры в разделе **«Просмотр»** открывает подсказку.
- **«Положить на поверхность»** укладывает выбранный предмет плашмя с сохранением X и Z. Кнопки отмены и повтора восстанавливают преобразования, создание и удаление предметов.
- Включи **штатные точки лута**, чтобы увидеть их объёмы и выбрать свободное место для Proxy.
- **F4 / «Персонаж»** включает одетого персонажа для проверки действия «Взять» и раздела «Поблизости». Закрой инвентарь и нажми F4 для возврата. Интерфейс персонажа скрыт во время редактирования.
- На панели инструментов есть фокус на опоре и экспорт. **«XML предмета» / F10** сохраняет выбранную вещь и всю опору; **«XML всей опоры»** — связанные с ней предметы на земле. **F11** переключает диагностику. Ошибки показываются в отдельном виджете с кнопкой закрытия.

Поиск принимает часть названия, не учитывает регистр и крайние пробелы и раскрывает подходящие ветки без ограничения в 100 результатов. «Объекты» ищутся по classname, «Предметы» — и по названию на языке клиента, и по classname. Разные классы с одинаковыми названиями остаются отдельными строками. Каталоги используют загруженные конфиги, включая дополнительные моды; конкретные сторонние классы могут потребовать отдельной проверки.

Дизайн интерфейса вдохновлён World Editor из Arma Reforger.

## Где лежит результат

По умолчанию:

```text
%LOCALAPPDATA%\ProxyPlacementTool\profiles\ProxyPlacement\<classname опоры>\<сеанс UTC>_scene_<номер>.xml
```

Повторный экспорт той же опоры в текущем сеансе обновляет её файл. Новые сеансы и другие опоры получают отдельные файлы. Предметы в руках/инвентаре не включаются в экспорт, пока не окажутся на земле. `selection.xml` и `<classname>.proxy.xml` — дополнительные файлы последнего выбранного предмета.

Папка `profiles` содержит журналы и JSON-проекты в `ProxyPlacement\Projects`. Папка `sessions` хранит служебные копии стартовой миссии. Другой каталог данных можно указать параметром `-RuntimeRoot`.

## Применение к экономике лута

Экспорт содержит фрагмент для `mapgroupproto.xml`, например:

```xml
<group name="Land_Garage_Row_Small">
  <dispatch>
    <proxy type="CanisterGasoline" pos="0 0.2 0" rpy="20 0 0" />
  </dispatch>
</group>
```

Значения здесь иллюстративные; используй координаты своего экспорта. Добавь `dispatch` в соответствующий прототип, сохрани нужные обычные контейнеры и остальные настройки здания. Для итогового появления предмета также нужны экземпляр здания, зарегистрированная группа и подходящие настройки экономики, включая `types.xml`.

Редактор не устанавливает экспорт автоматически на сервер. Предпросмотр создаётся скриптом; в целевой миссии предметы должна создавать CE. Сравни результат после нового запуска тестовой экономики. Экспортированные файлы разделены по экземплярам для удобства работы, но CE-прототип с одним classname обычно применяется ко всем его экземплярам: не добавляй несколько одноимённых групп вслепую.

## Область применения и ограничения

- Отмена и повтор охватывают положение, поворот, создание и удаление предметов. Delete удаляет выбранный предмет; в текстовых полях клавиша продолжает редактировать текст.
- Опора имеет ориентацию 0 и масштаб 1. Поворот самой опоры не поддерживается; преобразование проверено для CE-группы `rpy="0 0 0" a="90"`.
- Готовые XML требуют настройки целевой миссии; обычный лут автоматически не перестраивается.
- Проверки в обычном клиенте и мультиплеере не заявлены. Эта версия предназначена для авторов конфигурации на offline-площадке Test Range.

При сообщении об ошибке приложи версию DayZDiag, classnames опоры/предмета, шаги воспроизведения и соответствующие строки RPT/script log. XML помогает проверить ошибки позиции и углов.
