## Подключение

Найди `<group name="Land_Village_Pub">` в `mapgroupproto.xml` целевой миссии. Добавь записи `<proxy>` из примера в существующий `<dispatch>` или вставь блок `<dispatch>...</dispatch>`, если у группы его нет. Сохрани её атрибуты, штатные контейнеры лута и остальные нужные настройки.

Обёртка `<prototype>`/`<group>` в XML указывает целевой класс. Объедини содержимое dispatch с существующим прототипом; файл не заменяет весь `mapgroupproto.xml`. Раскладка задана для класса здания и может затронуть все экземпляры этого паба, использующие данный прототип.

Проверь настройки `types.xml`, фактический спавн через CE и доступность предметов в целевой миссии. См. [общую инструкцию примеров](../../README-RU.md#использование-примера).
