# Примеры размещения лута

[English](README.md) · [Инструкция редактора](../README-RU.md)

Раскладки, созданные с помощью Proxy Placement Tool. В каждом примере есть экспортированный фрагмент CE XML и инструкция для соответствующего класса здания или остова. Добавлять примеры можно независимо от релизов редактора.

| Classname здания/остова | Раскладка | Предметов | Демонстрация |
| --- | --- | ---: | --- |
| `Land_Village_Pub` | [Паб из видео](Land_Village_Pub/pub-demo/README-RU.md) | 8 | [Видео](https://youtu.be/EHs8mHtc7_s) |

## Использование примера

1. Открой страницу раскладки и скачай XML. На GitHub открой файл и нажми **Download raw file** либо сохрани содержимое **Raw** как XML-файл.
2. Найди соответствующую `<group name="...">` в `mapgroupproto.xml` целевой миссии.
3. Если у группы уже есть `<dispatch>`, добавь в него записи `<proxy>` из примера. Если его нет, вставь блок `<dispatch>...</dispatch>` из примера внутрь существующей группы.
4. Сохрани атрибуты группы, штатные контейнеры лута и остальные нужные настройки. Пример является фрагментом, а не полной конфигурацией миссии.
5. Проверь настройки соответствующих предметов в `types.xml`, затем фактический спавн через CE, позиции, углы, действие «Взять» и «Поблизости» в своей миссии. Используй [критерии проверки точки](../README-RU.md#критерии-проверки-точки).

Прототип задаётся для classname здания и может затронуть все соответствующие экземпляры, использующие этот прототип. Выбирай нужную раскладку для класса. Объединение раскладок добавляет предметы из каждой; повторная вставка тех же записей может продублировать размещения.

Для каждого примера указан статус проверки. Предпросмотр в редакторе, режим персонажа и демонстрационное видео сами по себе не подтверждают фактический спавн через CE в целевой миссии.

## Хранение новой раскладки

Создай папку `examples/<classname здания>/<название раскладки>/`, например `examples/Land_Village_Pub/pub-demo/`. Короткое название раскладки позволит хранить несколько вариантов для одного класса.

Добавь:

- `dispatch.xml`: исходный экспортированный XML с сохранёнными координатами и углами.
- `README.md` и `README-RU.md`: classname здания, описание, список предметов, порядок подключения и сведения о выполненных проверках.
- По возможности — сохранённый JSON-проект редактора для повторного открытия сцены, настоящие скриншоты или ссылку на видео. Сохранение проекта и экспорт XML выполняются отдельно; сохраняй оба файла, если хочешь продолжать редактировать пример.

Текущий пример паба содержит XML и ссылку на видео; редактируемый проект и скриншоты пока не добавлены.
