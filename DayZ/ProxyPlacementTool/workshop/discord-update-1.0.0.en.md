**Proxy Placement Tool — 1.0.0 is live!**

The first stable release is now available. Place loot at different angles relative to buildings and wrecks, then export CE dispatch XML.

**What's new since 0.4.0-alpha:**
- Delete selected items, with Undo/Redo for item creation and deletion as well as placement edits.
- Unsaved-change protection before opening another project, replacing the building/wreck or leaving through the in-game menu.
- An Items tree with Common and map branches, weapon/magazine calibers, clothing families and more equipment subgroups.
- More object groups: containers, barns, cement works, castles, churches and House/City building families.
- 3D hover previews for buildings, wrecks and supported StaticObj entries, plus highlighted classnames.
- F4 switches between editor and character mode without triggering a gesture.

Here's a short demo of item placement in a pub. Share your own arrangements, feedback and bug reports in this thread!
